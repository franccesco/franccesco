# About-me site

Source for the personal site at `franccesco.github.io/franccesco/`.

## Enable GitHub Pages

1. Push this branch to `origin/main`.
2. Repo **Settings → Pages**.
3. **Source**: Deploy from a branch.
4. **Branch**: `main`, **Folder**: `/docs`.
5. Save. First build takes ~1 min; URL appears in the same panel.

The site URL will be:

- `https://franccesco.github.io/franccesco/` — since this is the profile repo, Pages serves at the repo subpath.
- For a bare `https://franccesco.github.io`, move `docs/*` into a new repo named `franccesco.github.io` and serve from `/` on `main`.

## Editing

- Identity (name, email, handles): `Components.jsx`, top of file — the `ME` object.
- Essays index: `articles/index.json`. The homepage automatically uses its first three entries.
- Work history: `Landing.jsx` — the `WorkLine` entries.
- Visual tokens (colors, type, spacing): `colors_and_type.css`.
- Font files: copied from pinned Fontsource packages by `scripts/copy-fonts.mjs` during builds.

## Development

The browser receives a production bundle generated by Vite; JSX is never compiled in a visitor's browser.
Components use Preact's React-compatible API to keep the production runtime small.
Use the Node version declared in `.nvmrc` and the npm version declared in `package.json`.

```sh
npm install
npm run dev
```

Before committing source changes, regenerate the files served by GitHub Pages:

```sh
npm run check
```

`package-lock.json` pins the dependency graph. CI checks the build, audits production dependencies,
enforces homepage bundle and portrait budgets, and fails when `docs/build` is stale. Dependabot
proposes grouped dependency updates each week.

## Notes

- Theme cycles light → dark → system via the nav button. Choice is persisted in `localStorage` under `fo:theme`. System follows `prefers-color-scheme`.
- Routing is hash-based (`#/writing`, `#/contact`) so deep links survive on Pages.
- `.nojekyll` keeps Pages from running Jekyll over the files.
- Article parsing, sanitizing, and syntax highlighting are split into a lazy chunk and load only when an essay is opened.
